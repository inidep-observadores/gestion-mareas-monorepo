# Antigravity Agent Configuration

Este directorio contiene configuraciones específicas para el agente de IA Antigravity.

## Estructura

- `skills/`: Contiene capacidades modulares que el agente puede cargar dinámicamente. Cada skill reside en su propia subcarpeta con un archivo `SKILL.md`.
- `workflows/`: Define secuencias de pasos para tareas comunes en el proyecto.

## Uso

El agente escanea este directorio al inicio de la sesión para registrar las habilidades disponibles y entender los flujos de trabajo recomendados para este repositorio.
