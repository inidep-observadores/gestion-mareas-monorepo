# Esquema de Contenido: Profundidad Funcional

Este documento detalla la estructura propuesta para la sección "Profundidad Funcional" (`03_DETALLE_FUNCIONAL.md`). El objetivo es desglosar la complejidad del sistema en módulos comprensibles y explicados con un enfoque operativo.

---

## Estructura Propuesta

### Introducción Modular
*   Breve explicación de la arquitectura modular de SIGMA: "Un sistema, múltiples dimensiones".

### 1. El Núcleo Operativo: Gestión del Ciclo de Vida de Mareas
*Enfoque: Trazabilidad y Workflow*
*   **La Marea como Eje Central**: Explicación de que todo gira en torno a la "Carpetas de Marea" digitales.
*   **Fases del Proceso (Workflow)**:
    *   *Designación*: Asignación inteligente (validación de disponibilidad de observador).
    *   *Etapas de Navegación*: Registro granular de Zarpadas, Arribos y Entradas en Zona. Diferenciación clara entre "Días Navegados" (buque) y "Días de Marea" (afectación del personal).
    *   *Cierre y Rendición*: El fin del ciclo administrativo y el paso de datos al área científica.

### 2. Capa de Inteligencia: Monitoreo y Alertas
*Enfoque: Detección Proactiva y Geoespacial*
*   **Gestión por Excepción (Alertas)**: El sistema vigila 24/7. Detección de inconsistencias temporales (fechas imposibles) y operativas.
*   **Visor de Trayectorias y Geocercas**:
    *   Integración de mapas para validar visualmente la operación.
    *   Verificación de actividad en zonas habilitadas/vedadas.
    *   Contexto de 24hs alrededor de cada alerta para entender "qué pasó".
*   **Tableros de Control (Dashboards)**: Visión panorámica para la Dirección (resumen de fuerza laboral, buques activos, alertas pendientes).

### 3. Gestión de Recursos y Backoffice
*Enfoque: Administración de Activos*
*   **Legajo Digital del Observador**:
    *   Historial completo de navegaciones.
    *   Estado actual (Disponible, Embarcado, Licencia).
    *   Métricas de desempeño individuales.
*   **Registro de la Flota Comercial**: Base de datos de buques, historial de coberturas y pesquerías habituales.
