# 3.3 Gestión de Recursos y Backoffice

> **Administración Eficiente del Capital Humano y Material**

---

## El Soporte de la Operación

Detrás de cada marea exitosa hay una gestión logística compleja. SIGMA digitaliza y organiza los activos fundamentales del Programa: sus observadores y la flota monitoreada.

---

## 1. Legajo Digital del Observador
El sistema reemplaza las carpetas físicas y planillas dispersas por un perfil digital unificado para cada observador.

*   **Identidad y Estado:** Vision rápida de quién es el observador y su situación actual (Disponible, Embarcado, Vacaciones, Licencia Médica). Esto alimenta directamente al motor de asignaciones, impidiendo designar a personal no disponible.
*   **Hoja de Vida Operativa:** Un historial automático e inalterable de todas las campañas realizadas: buques, fechas, días navegados y pesquerías cubiertas.
*   **Capacidades y Desempeño:** Registro de habilidades específicas (ej. muestreo de mamíferos, bycatch) para asegurar que se envíe al perfil adecuado para cada misión.

## 2. Registro Maestro de Buques
La flota comercial es dinámica. SIGMA mantiene una base de datos viva de los buques operativos.

*   **Perfil Técnico:** Información crítica para el embarque (habitabilidad, seguridad, capacidad).
*   **Historial de Cobertura:** ¿Cuándo fue la última vez que un observador subió a este buque? El sistema permite identificar "vacíos de cobertura" para priorizar designaciones y asegurar una muestra representativa de la flota.

## 3. Backoffice y Administración
Herramientas transversales para la gestión diaria del Programa:

*   **Gestión de Usuarios y Roles:** Control de acceso granular (Coordinadores, Administrativos, Visualizadores), asegurando que cada usuario vea solo lo que necesita.
*   **Auditoría (Audit Logs):** Seguridad institucional. El sistema registra cada acción relevante (quién autorizó una marea, quién modificó un dato sensible), garantizando transparencia total ante auditorías internas o externas.
