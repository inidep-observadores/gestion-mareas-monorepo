# Changelog v0.4.0

## 2026-03-30 - Gestión de Protocolización y Control de Acceso

### Backend
#### [NEW] Endpoints de Protocolización Protegidos
- **RBAC**: Restricción de acceso a los roles `admin` y `coordinador` para todas las operaciones de protocolización.
- **Rutas**:
  - `POST /mareas/protocolizacion/enviar`: Envío de informes a protocolizar.
  - `POST /mareas/protocolizacion/confirmar/:id`: Confirmación final de datos de protocolización.
  - `GET /mareas/protocolizacion/pendientes`: Listado de mareas para enviar.
  - `GET /mareas/protocolizacion/en-espera`: Listado de mareas enviadas.
  - `GET /mareas/protocolizacion/completas`: Listado de mareas ya protocolizadas.

#### [MOD] Gestión de Almacenamiento de Informes
- **Ruta de Archivos**: Migración de la carpeta de almacenamiento de `/uploads/protocolizacion` a `/uploads/informes_marea`.
- **Configuración**: Soporte para la variable de entorno `MAREA_INFORMES_DIR` para definir el subdirectorio de informes basado en `UPLOADS_PATH`.

### Frontend
#### [NEW] Dashboard de Protocolización de Mareas
- **Interfaz Integral**: Nuevo centro de control con tres estados operativos:
  - **Pendientes de Envío**: Gestión de carga de archivos y selección de canal.
  - **Esperando Confirmación**: Monitoreo de mareas enviadas a organismos externos.
  - **Mareas Protocolizadas**: Historial de mareas completadas.
- **Carga de Archivos Drag & Drop**: Implementación de zona interactiva para adjuntar informes `.docx` directamente en las fichas de marea.
- **Flujos de Envío Diferenciados**:
  - **Canal Regular (Email)**: Simulación de cliente de correo para envío institucional.
  - **Canal Externo**: Registro manual de fecha de envío para trámites fuera de plataforma.

#### [MOD] Usabilidad y Refinamiento de Interfaz
- **Ordenamiento Inteligente**: Implementación de orden descendente global (Tipo, Año, Número) en todas las pestañas de protocolización.
- **Diálogo de Confirmación Mejorado**:
  - Formato de código de marea unificado (`TIPO-NRO-AÑO`).
  - *Autofocus* automático en el campo de número de protocolo al abrir el diálogo.
  - Integración de `DatePicker.vue` para selección de fecha con formato limpio.
  - Validación dinámica: habilitación de botones solo ante formularios completos.
- **Formato de Fechas**: Presentación de fechas en formato `DD/MM/AAAA` (sin hora) en todas las vistas de protocolización.

#### [LOCK] Control de Acceso (RBAC)
- **Sidebar**: Ocultamiento del ítem "Protocolización" para roles no autorizados (restringido a Admin y Coordinador).
- **Protección de Rutas**: Configuración de `meta.roles` en el router de Vue para prevenir accesos manuales por URL.
