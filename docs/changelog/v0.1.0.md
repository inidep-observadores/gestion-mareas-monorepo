# Changelog v0.1.0

## [v0.1.0] - UNRELEASED

### Backend
#### [MOD] Endpoint Zona Austral
- Implementado cálculo automático de días en Zona Austral (Lat <= -50º S).
- **Mejora**: El endpoint ahora devuelve un desglose detallado por cada etapa de la marea, incluyendo el total de días y la lista de fechas detectadas por etapa.
- Requisito de integridad: Mínimo 2 puntos de trayectoria por día local dentro de cada etapa.
- Nuevo endpoint: `GET /mareas/:id/zona-austral`.

### General
- Refinamiento de reglas de integridad de base de datos para la gestión de mareas.
- Mejora en los tiempos de verificación de disponibilidad de buques y observadores.
